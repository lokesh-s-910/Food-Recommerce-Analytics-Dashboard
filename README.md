# Food-Recommerce-Analytics-Dashboard
## Project Overview
Developed an interactive Power BI dashboard to analyze food order trends, restaurant performance, customer segmentation, and delivery efficiency

## Objective
.Analyze overall orders and revenue performance.
.Identify top-performing and rated restaurants and cuisines.
.Understand customer ordering behavior.
.Evaluate delivery performance and cancellation trends.

## Key Features
*Top 10 Restaurants by Revenue
. Top 10 Most Ordered Cuisines
.City-Wise Order Status Distribution
.Premium, New, and Repeat Customer Segmentation
.Order Distribution by Cost for Two
.Restaurant Rating-Wise Order Analysis
.Monthly Average Delivery Time
.Delivery Status Performance

## Tools And Technologies
.PowerQuery
.DAX
.PowerBI
.Data Visualization
.Data Modeling
